# Решение AdScale



## Цель проекта

Обеспечить интеграцию с крупным DSP-партнёром, выдержать рост нагрузки до 18 000 RPS в ближайшие 3 месяца и подготовить систему к 50 000 RPS через год, сохраняя SLA (P99 < 80 мс) и непрерывность бизнеса.



## Содержание

- **Task1** - архитектурная диагностика и целевое видение.

 - `AS-IS.md` - анализ текущей архитектуры.

 - `drivers.md` - архитектурные драйверы.

 - `TO-BE.md` - описание целевой архитектуры.

 - `diagrams/` - диаграммы C4 Container для целевого состояния.

 - `adr/` - Architecture Decision Records.
