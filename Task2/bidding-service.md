# Спецификация сервиса ставок (Bidding Service)



## Границы сервиса

Сервис ставок отвечает за:

- Приём списка кандидатов (объявлений) от Рекламного сервера.

- Применение бизнес-правил для расчёта ставок (включая таргетинг, бюджет, приоритеты).

- Участие в аукционе: определение победителя на основе максимальной ставки.

- Возврат победителя и цены (win price) в Рекламный сервер.

- Логирование результатов аукциона для финансового учёта (асинхронно через Kafka).



**Что НЕ входит в границы:**

- Подбор кандидатов (это задача Рекламного сервера).

- Генерация HTML/JS-разметки (Сервис выдачи).

- Сбор статистики показов/кликов (Сервис статистики).

- Финансовые транзакции списания (Финансовый сервис) - только логирование.



## API сервиса

Сервис предоставляет синхронный gRPC-интерфейс для Рекламного сервера:



```protobuf

service BiddingService {

    rpc PlaceBid (BidRequest) returns (BidResponse);

}



message BidRequest {

    string request_id = 1;

    User user = 2;

    repeated AdCandidate candidates = 3; // предварительно отфильтрованные

    AuctionContext context = 4;

}



message BidResponse {

    string request_id = 1;

    AdCandidate winner = 2;         // выигравшее объявление

    double win_price = 3;           // цена, которую заплатит рекламодатель

    int64 processing_time_ms = 4;   // метрика для мониторинга

}

```



## 3. Зависимости от других сервисов



Сервис ставок взаимодействует со следующими компонентами:



- Redis (кэш) – синхронное чтение. Хранит актуальные данные кампаний, объявлений, модификаторов ставок. Это основной источник данных для расчётов.

- PostgreSQL (основная БД) – синхронное чтение и редкая запись. Используется как источник истины при промахах кэша, а также для записи истории аукционов (AuctionLog) в целях аудита.

- Kafka – асинхронная публикация событий. После каждого аукциона отправляется событие `AuctionWon`, которое потребляют Финансовый сервис (для списания средств) и Сервис аналитики (для отчётности).



Сервис не зависит от UI, платёжного шлюза, сервиса статистики и других вспомогательных компонентов.
