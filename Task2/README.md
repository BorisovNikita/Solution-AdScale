# Задание 2. Проектирование RTB и интеграции с DSP



Этот раздел содержит проект критического компонента - сервиса ставок (Bidding Service) для интеграции с новой DSP-площадкой, обеспечивающего соблюдение жёстких SLA по времени отклика и надёжности.



## Состав

- `bidding-service.md` - спецификация сервиса ставок: границы, API, зависимости, модель данных.

- `interaction.md` - схема взаимодействия, выбор протоколов (реализация при помощи gRPC, REST, Kafka), обоснование.

- `api-gateway.md` - дизайн API Gateway для DSP-интеграции: маршрутизация, rate limiting, аутентификация, Circuit Breaker, мониторинг.

- `diagrams/` - диаграммы в формате PlantUML.



Все решения приняты с учётом требований по латентности (P95 < 100 мс), масштабируемости и отказоустойчивости.
