# Задание 3. Данные, масштабирование и отказоустойчивость



Этот раздел содержит стратегию работы с данными в микросервисной архитектуре AdScale, обеспечивающую масштабируемость и отказоустойчивость хранилищ.



## Состав

- `database-strategy.md` – выбор базы данных для каждого сервиса с обоснованием.

- `scaling.md` – стратегии репликации и шардирования, CQRS, read replicas.

- `caching.md` – дизайн кэширования: что кэшировать, TTL, инвалидация, прогрев кэша.

- `event-streaming.md` – архитектура Kafka: топики, схемы, группы потребителей, политика хранения.

- `failover.md` - Отказоустойчивость данных

- `diagrams/` – диаграммы данных.
